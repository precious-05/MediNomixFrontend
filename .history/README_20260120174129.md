# MediNomix - Medication Safety Guard

## 📋 Project Overview

MediNomix is an advanced AI-powered medication safety system designed to prevent drug name confusion errors in healthcare settings.

## 🎯 Problem Statement

Medication errors due to drug name confusion are a significant patient safety concern. Look-alike and sound-alike drugs can lead to serious medical errors, adverse events, and patient harm.

## 🏗️ System Architecture

### Backend (FastAPI - `main.py`)

- **Purpose**: API server for drug analysis
- **Database**: PostgreSQL with NeonDB hosting
- **Main Functions**:
  1. Search drugs and calculate confusion risks
  2. Store drug information from OpenFDA API
  3. Calculate similarity scores using multiple algorithms
  4. Provide analytics data for dashboard

### Frontend (Streamlit - `app.py`)

- **Purpose**: User interface for drug analysis
- **Features**:
  1. Drug search and analysis
  2. Real-time analytics dashboard
  3. Interactive heatmaps and charts
  4. Modern UI with medical theme

## 🛠️ How It Works

### 1. Drug Search Process

```
User Input → FastAPI Backend → OpenFDA API → Analysis → Results Display
```

### 2. Risk Calculation

- **Spelling Similarity**: Levenshtein distance, fuzzy matching
- **Phonetic Similarity**: Soundex, Metaphone algorithms
- **Therapeutic Context**: Drug class and purpose analysis
- **Final Risk Score**: Weighted combination of all factors

## Quick Start

### 1. Backend Setup

```bash
cd backend
pip install -r requirements.txt
python main.py
# Runs at http://localhost:8000
```

### 2. Frontend Setup

```bash
cd frontend
pip install -r requirements.txt
streamlit run app.py
# Runs at http://localhost:8501
```

### 3. Test the Application

1. Open browser to `medinomix.streamlit.app`
2. Search for a drug (e.g., "lamictal")
3. View confusion risk analysis
4. Explore analytics dashboard

##  Main API Endpoints

| Endpoint | Method | Description |
|----------|--------|-------------|
| `/api/search/{drug_name}` | GET | Search and analyze drug |
| `/api/metrics` | GET | Get dashboard metrics |
| `/api/top-risks` | GET | Get top risk pairs |
| `/api/heatmap` | GET | Get heatmap data |
| `/health` | GET | Health check |
